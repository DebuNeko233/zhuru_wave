# 合成波形测试样本

`synthetic_triangle_examples.zip` 来自原始 `trianglewave_detection.zip/test_data/` 中的 7 个小型 CSV，不是工厂实际采集数据。

包含：标准三角波、削波三角波、圆顶三角波、毛刺三角波、零点台阶三角波、顶峰突降三角波及另一个顶峰突降示例。文件原始中文名称保持不变。

- SHA-256: `410d278a390e7a11ed138e5d6337ee70bb5a0dfeb136ee49002333854dff2a1b`
- 压缩包大小：2894 bytes
- 用途：初步规则单元测试、回归检查、算法可视化；**不代表**这些样本已经充分覆盖现场缺陷。
- 不能作为双通道同步 XY 李萨如训练/验证样本使用。

当前在线后端 `f6.py` 的输入要求至少 1000 点；部分短样本可能需要在测试端合理构造重复周期，且不得把合成波形当作真实检测准确率依据。
