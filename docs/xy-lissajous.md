# XY 李萨如轨迹页

入口：左侧 **通道 → XY 李萨如**（`#/lissajous`）。在同一页面选取 X、Y 轴对应的通道（X1 / Y1 / X2 / Y2），不允许使用同一通道作为两轴。

- **实时通道**：取同一批 HT6004BX 采集数据、相同的原始采样索引，不能用两个通道独立修正过的 `showData` 配对。设备尚未连接时，不会出现假轨迹。
- **同步 CSV**：点击「导入同步 CSV」，从一个文件读取至少两列通道原始值。必须包含单调连续的 `sample_index`，而且每行包含所有通道的数据。最多 25 MB / 250000 个样本；不支持把两份独立单通道文件自动拼接，以免造出错误李萨如图形。
- **窗口**：支持 1024 / 2048 / 4096 样本视窗。可拖动下方滑杆查看本地 CSV 不同时间段。绘图坐标为归一化数值；不要理解为电压。
- **算法**：调用现有 Python `POST /wave_check_pair`。显示清晰度、轨迹厚度、内部填充比例、多边形边数、可计算时的相位差。未设现场校准阈值时状态为 `UNVERIFIED`；无后端仍可绘图，但指标不显示。既不把合成文件的 `scenario` 标签当判定，也不直接产生设备报警。

## 生成演示数据

在仓库根目录运行：

```bash
python scripts/generate_xy_demo.py --output demo/xy --samples 60000
```

将产生下列合成同步记录（非真实离子注入机采集）：

- `01_clear_octagon.csv`：清晰八边形轨迹（X1/Y1）。
- `02_blurred_octagon.csv`：发散、内部填充明显（X1/Y1）。
- `03_distorted_octagon.csv`：轻度变形、部分内部填充（X1/Y1）。
- `04_four_channels_compare.csv`：同一文件同时包含 X1/Y1 的清晰轨迹与 X2/Y2 的发散轨迹，用下拉框即可切换比较。

每个文件默认 **60000** 个同步采样索引，采样率元数据为示例值 `125000` Hz；`amplitude_unit=raw`。这些 XY 轨迹由分段线性二维八边形路径生成，单轴可能包含短平台，**仅用于 UI、算法和同步性的演示**，不代表实际注入机给定的两个理想三角扫描电压的物理时序。

CSV 格式为：

```csv
meta_key,meta_value,sample_index,X1,Y1
format,zhuru-wave-v1,,,
sample_rate_hz,125000,,,
channel_count,2,,,
channel_names,X1|Y1,,,
amplitude_unit,raw,,,
synchronized,true,,,
source,synthetic,,,
,,0,-100.0,120.0
,,1,-98.3,121.6
```

行数据必须来自同一个采样时基。单通道 CSV 导入保持原有通道详情页功能，本次新入口专门用于同步多通道 XY 图；本页面不对示波器波形质量作额外报警判定。

## 运行

1. 启动 `backend/f6.py`（计算分析指标所需）；实时图仅在采集设备产生相同时基的数据时显示。
2. 在 `desktop` 运行 `npm run dev` 或重新构建打包，左侧「通道 → XY 李萨如」。
3. 选择「同步 CSV」并导入第 4 份四通道对比文件，先选择 `X1/Y1`，再切换 `X2/Y2`。
4. 比较轨迹是否清晰，清晰度数值仅做参考；真实现场判定前必须用用户标注的同步 X/Y 数据校准。
