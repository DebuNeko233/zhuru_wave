# 现场采样文件

用户现场导出的 `60x1.csv`、`60x2.csv` 是带三行文字头的 TAB 分隔文本：

```text
DRC_File: 60x1.0.drc
Channels_qnty: 1 Header_size: 164 Time_DIV: 2000000
CH   Index   Value
1    0       20625.3
...
```

两文件分别约 242.9 万、181.0 万个样本，幅度约为正负 2 万量级。`Value` 是导出值，没有按硬件探头比例转换成伏特；`Index` 只是该文件内的样本序号。

对比 / 标注必须使用**同一采集会话且同步**的两个通道；两个独立文件即使频率接近也不等价于同时间轴，不能直接逐行配对为李萨如图。请导出同一触发/同一扫描窗口下的 `index,ch1,ch2` 数据，并记录采样率、触发时间、硬件档位和可能的时间偏移。

`tools/inspect_drc_csv.py` 会读取单通道原始码值并输出统计，**不**做未经证实的电压换算。
