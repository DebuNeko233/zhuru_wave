# 当前在线检测算法与待改进点

`backend/f6.py` 主入口 `wave_check` -> `wave_check_real` -> `split_single_period` -> `panjue`。

- `split_single_period`：根据符号变化寻找过零点，构造完整周期。
- `moving_average`：平滑波形，窗口默认 9。
- `is_square_like`：差分幅值分位数 + 平坦区比例检查。
- `is_triangle_like`：差分幅值/平坦比例/斜率符号变化粗判三角波。
- `calculate`：计算两个尺度上的斜率差。
- `func_robust`：用 MAD 自适应阈值选择和合并候选突变点。
- `pass_flag`：合格周期（1–2 个突变点）比例 >= `rate`，且三角波判定占比 >= 0.55，并 >= 方波占比。

## 需要分开表达的三类结果

1. 单通道**波形质量**：线性拟合误差、异常折点/毛刺、峰谷平台、周期稳定性。
2. 两通道**联合轨迹**：同步配对点构成的 XY 图是否为细而稳定的八边形。
3. **设备/算法运行状态**：通信超时、输入太短、参数无效、无可分割周期，不能归为“实际波形异常”。

当前 `f6.py` 没有完成第 2 项。原始算法的 `1–2 个突变点` 不等于真实缺陷标注；不建议直接把所有 `tubiandian_list` 标为毛刺。
