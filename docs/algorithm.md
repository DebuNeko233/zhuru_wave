# 原始 f6 算法与下一阶段要求

## 在线检测（现有实现）

1. 读取 `data.wave`（前 10000 点；请求总长度至少 1000）。
2. `split_single_period` 用符号变化检测过零点，按 `period_step` 规则取完整周期。
3. 每周期 `moving_average` 平滑；`is_square_like` 依据差分分位数识别近似方波；`is_triangle_like` 依据平坦比例与差分符号翻转次数寻找三角波特征。
4. `calculate` 求步长 `step1` 的斜率以及步长 `step2` 的斜率差；`func_robust` 以 `max(base_epsilon, adaptive_k × 1.4826 × MAD)` 为阈值检测突变并合并邻近峰。
5. 周期内检测到 **1～2 个突变点**视作计数合格；计算 `good_period_rate`。
6. `triangle_detected = (triangle_ratio >= 0.55) and (triangle_ratio >= square_ratio)`。
7. `pass_flag = (good_period_rate >= rate) and triangle_detected`。

其中 `good_period_rate` 是规则通过比例，**不是准确率**。斜率差处的“突变点”也可能是三角波正常顶点/谷底，而不一定是缺陷。

## 现有主要局限

- `is_triangle_like` 未显式衡量两条斜边的线性拟合残差，正弦波或其他平滑形态可能出现混淆。
- `split_single_period` 对直流偏置、过零抖动、零平台比较敏感。
- `epsilon` 与真实输入码值量纲必须严格一致；不能未经换算直接把电压阈值用于原始码值。
- `auto_params` 目前仅搜索“每周期 1～2 个突变点”的指标，不代表对人工标注缺陷的验证优化。
- Python 后端当前不接受同步双通道输入，因此不能直接做李萨如图八边形评估。

## 后续联合判定设计（尚未实现）

**单路质量**：分别计算上升/下降沿线性拟合 RMSE、峰谷附近额外拐点、局部毛刺、周期/振幅稳定性与采样可信度。

**双路质量**：在同步 XY 点对上先评估中心与幅值归一化、分段轨迹的多边形拟合、边界厚度/轨迹重复性、内点填充率、中心对称性和轮廓闭合性。避免仅用凸包边数判断八边形。

**综合输出**：分开报告 `x_ok`、`y_ok`、`lissajous_ok`、采集同步性、检测失败原因及置信/质量指标。不得在无同步信息、无有效周期或设备通信失败时直接判为“异常波形”。

所有阈值需用人工审核的**正常/异常实测样本**调参；尚无经现场验证的指标、分数或检出率。
