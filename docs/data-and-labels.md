# 数据格式、现场样本与标注约定

## 已知 CSV 格式

两份现场数据分别命名为 `60x1.csv` 和 `60x2.csv`，头部为：

```text
DRC_File: 60x1.0.drc
Channels_qnty: 1 Header_size: 164 Time_DIV: 2000000
CH \t Index \t Value
1\t0\t20625.3
```

不能用普通逗号分隔的 CSV 读取逻辑直接把第一行当作三列表头。有效数据列为 `CH, Index, Value`，分隔符为 Tab，前三行是元信息。Value 是原始导出幅值，**不是 V、mV 等物理电压**。

## 现场文件统计（静态解析）

| 文件 | 样本点数 | 最小值 | 最大值 | 均值 |
| --- | ---: | ---: | ---: | ---: |
| 60x1.csv | 2,428,928 | -23,752.8 | 24,375.4 | 506.9 |
| 60x2.csv | 1,810,432 | -16,877.7 | 18,125.3 | 519.6 |

两组单通道波形过零点间隔中位数均约为 24 样本，完整周期粗略约 48 样本。该估计不能替代采样率、时基和同步触发校核。

## 用户给定的现场判据

- 所提供现场图片中：前四张示意**不正常三角波**，最后一张示意**正常三角波**。
- 还必须检查两路三角波之间的 **XY 李萨如轨迹**，目标为**边界清楚、线条较薄、内部不过度填充的八边形**。
- 中间几张李萨如图片可作为轨迹外观参考，但**不能仅从截图自动推断已具备对应的同步原始采样数据**。
- “看起来像八边形”只是初始工程要求；八边形边数、面积、边宽、轨迹散布、中心空心度、线性度等需要量化与现场标定。

## 同步采集要求

```csv
index,ch_x,ch_y
0,1234,-5678
1,1456,-5432
2,1678,-5000
```

这是**目标格式示例**，不是实测。XY 必须同次采集、同采样率、共用触发基准、对应同一时刻，避免将独立文件按 Index 强行配对。两份现场单通道 CSV 长度不同，**不能直接视作已同步的双通道对**。

建议保留元信息：设备型号、通道、采样率、时间基、触发方式、工作档位、采样单位/码值、文件来源、人工标签、同期运行状态。

## 发布与隐私

原始百万级数据和现场照片保留在经授权的原始资料库/实验记录中，公开仓库默认不提交。小型合成测试波形应标为 `synthetic`，不能冒充现场真值。
